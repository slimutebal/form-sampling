# Google Material Symbols attribution

The SVG files in this directory are unmodified copies of Google Material
Symbols, from the official
[`google/material-design-icons`](https://github.com/google/material-design-icons)
repository:

- `rule_settings_24px.svg`
- `data_exploration_24px.svg`
- `finance_mode_24px.svg`

Source path: `symbols/web/<icon>/materialsymbolsoutlined/<icon>_24px.svg`.

Copyright Google LLC. Licensed under the Apache License, Version 2.0.
See <https://www.apache.org/licenses/LICENSE-2.0>.

The source vectors must remain unmodified. This application renders them as
CSS masks only to apply an outer, theme-controlled monochrome color; no SVG
path data is changed.
